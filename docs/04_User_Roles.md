## User Roles

### Tournament Coordinator
Primary operator of BattleStation. Creates events, approves robots, generates brackets, controls matches, records winners, handles overrides, and monitors system health.

### Competitor / Driver
Registers one or more robots, checks in at the event, confirms robot information, competes in matches, presses Ready, and may Tap Out during a match.

### Referee
Oversees match safety and fairness. Can pause/resume matches, request unsticks, respond to arena issues, and confirm match outcomes.

### Inspector
Checks robot weight, safety, class compliance, weapon type, and special class rules such as Plastic Ant construction requirements.

### Spectator
Views public display information only: current match, next match, timer, winner, bracket, and event status.

### Pit Area Participant
Receives announcements about upcoming matches, staging, delays, and event status.

### System Administrator
Maintains BattleStation software, hardware, backups, updates, logs, configuration, and troubleshooting.
